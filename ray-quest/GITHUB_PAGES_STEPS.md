# Publish Ray Quest with GitHub Pages

Use the existing public repository:

`brianhageman/interactiveoptics`

## Upload the folder

1. Open `https://github.com/brianhageman/interactiveoptics`.
2. Click **Add file**.
3. Click **Upload files**.
4. Drag the local `ray-quest` folder into the upload area.
5. Commit directly to the `main` branch with a message like:
   `Add Ray Quest optics game`

## Enable GitHub Pages

1. Open the repository **Settings** tab.
2. Go to **Pages** in the left sidebar.
3. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**.

## Student links

After GitHub Pages finishes deploying, use:

- Game: `https://brianhageman.github.io/interactiveoptics/ray-quest/`
- Printable worksheet: `https://brianhageman.github.io/interactiveoptics/ray-quest/worksheet.html`
- Word worksheet download: `https://brianhageman.github.io/interactiveoptics/ray-quest/ray_quest_prediction_worksheet.docx`

Deployment can take a minute or two after upload.
